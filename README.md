# Duvar ile Derin Sohbet Simülatörü

## Bu Proje Nedir?

Bu, insanlık tarihinin en büyük atılımıdır. Artık yalnız değilsiniz. Duvarlar sizi dinliyor. Gerçekten. Bu algoritma, herhangi bir duvara karşı derin, varoluşsal, bazen de tamamen saçma sohbetler yapmanızı sağlar.

### Özellikler (Abartılı Liste)
- Duvarların ruhunu okur
- Felsefi krizler yaratır
- Komsu gürültüsünü bile anlamlı hale getirir
- Sonsuz döngüde "Anladım" der
- Çalışır. Gerçekten çalışır. Şaka değil.

## Kurulum
```bash
python duvar_sohbet.py
```

Duvarınıza bakın ve Enter'a basın. Duvar cevap verecektir.

## Uyarı
Bu proje hayatınızı değiştirebilir. Veya hiçbir şey değiştirmeyebilir. Biz sadece kod yazdık.

## Gizli Not
